# Archived documents

Kept for reference only. **Neither describes the current software.**

| File | Why it is archived |
|---|---|
| `EXTENSION_TUTORIAL.md` | Describes extending the old interactive shell (`rp_repl`), the `qsim_macro` evaluator, `qsim_num_theory` and a Shor's-algorithm package. None of these ship with QCLP_G. New commands are now added to `qclp_gates/rp_commands.pl` like the existing ones. |
| `rprolog_fd_reference_manual.docx` | Retitled "QCLP_G Reference Manual", but documents the retired `rp_fd/1` command interface (`rp_fd(solve(Example))` on named examples), `rp_fd_demo.pl`, `qoracle_sv.pl` and `qsim.pl`. Its sections on internal representations (fd_spec, oracle microcode events, ancilla naming) and generated QASM structure may still be useful background. |
